# 문제 교차 검수표

PRD 요구사항: "모든 문제에 출처 확인된 정답과 해설, 출시 전 2인 이상 교차 검수".
이 표는 `public/questions.json`에서 만들었습니다. 문제를 고치면 표도 다시 만들어 주세요.

## 검수 방법

1. 검수자 두 명이 각자 모든 문제를 확인합니다. 정답이 하나뿐인지, 다른 보기도 정답이 될 여지가 없는지, 해설이 사실인지 봅니다.
2. 문제가 없으면 자기 칸에 `O`, 고칠 점이 있으면 `X`와 이유를 적습니다.
3. 두 사람 모두 `O`인 문제만 출시합니다. `X`가 있으면 `public/questions.json`을 고친 뒤 다시 검수합니다.
4. 출시 후에는 통계 화면(랭킹 → 통계 보기)에서 정답률 10% 미만·95% 초과로 표시된 문제를 다시 봅니다.

"사전 확인"은 2026-11-02에 웹 자료로 미리 확인한 결과입니다. 사람 검수를 대신하지 않습니다.

## 사전 확인에서 바꾼 내용

- **6번**: "1919년 대한민국 임시 정부가 처음 수립된 도시는?" → "1919년 4월 '대한민국'이라는 국호를 정하고 대한민국 임시 정부가 수립된 도시는?". 보기 "블라디보스토크" → "베이징". 해설에 9월 통합 임시 정부 내용 추가.
- **29번**: 해설의 길이를 "본류 약 510km"로, 발원지를 "황지연못"으로 명시.
- **30번**: 해설의 길이를 "약 7,000km" → "7,000km 넘게".
